# Documentation artwork

`project-header.svg` is the project header, with the verified local check counts and the Azure services used in the hosting design. Its PNG copy supports previews that do not render SVG.

The three Azure service icons are unchanged files from Microsoft Azure Public Service Icons V24:

| File | Microsoft source file |
| --- | --- |
| `container-apps.svg` | `02989-icon-service-Container-Apps-Environments.svg` |
| `postgresql.svg` | `10131-icon-service-Azure-Database-PostgreSQL-Server.svg` |
| `key-vault.svg` | `10245-icon-service-Key-Vaults.svg` |

Source and permitted-use terms: [Microsoft Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/icons/). Microsoft retains ownership of its service icons.
